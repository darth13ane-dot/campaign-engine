# Reuse a session structure

From **Sessions**, choose **Prep templates**, or open Session Prep and choose **Use a template**. Templates provide reusable planning instructions for the GM to develop into a session. Your custom library is available across campaigns and game systems.

## Choose a starter

| Starter | Useful for | Suggested session length |
| --- | --- | --- |
| Investigation | Several leads, evidence, witnesses, and decisions under uncertainty | 180 minutes |
| Social event | Guests with separate priorities, negotiable offers, and public or private opportunities | 180 minutes |
| Exploration | Connected routes, readable risks, discoveries, and return options | 180 minutes |
| Dungeon expedition | Connected spaces, occupants with goals, entry choices, and withdrawal | 240 minutes |
| Heist | A negotiable objective, multiple access approaches, and changing pressure | 210 minutes |
| Downtime | Player priorities, projects, relationships, and next-session intentions | 120 minutes |

Each starter supplies opening guidance, five scene prompts including one optional scene, revelations, clocks, spotlight prompts, and prep tasks. Suggested times leave room for discussion, breaks, and improvisation. Adapt the order and omit anything your table does not need.

## Review it for a session

1. Choose the destination session in the library, then choose **Review for this session** on a template.
2. Read the **Planning prompts**. Standard entries begin included; optional entries begin unselected. Toggle **Include** or use **Clear selection** to choose the structure you want.
3. Open **Write this session’s details** to enter scene titles, situations, decisions, clues, clock labels, spotlight opportunities, or tasks. You can also leave fields empty and develop them later in Session Prep.
4. If appropriate, select **Use the suggested … minute session length**. This is an explicit replacement of the target session's time budget; leaving it unchecked preserves the existing budget.
5. Choose **Add selected to prep**. Selected entries append to the plan. Any opening text you wrote appends to the existing opening, with its planning guidance stored separately.

Selections and session writing save with the review. Use **Resume template review** from Session Prep to return after reopening the app. Applying consumes that review. Reviewing the same template again starts a fresh application and can add another set of entries.

If the source template, target preparation, or live-session status changes, the review requires attention. **Refresh review** rebuilds it from current material. Changed selections or session writing prompt a confirmation before replacement. The existing preparation remains saved. A deleted source template leaves its pending review available to inspect, with application blocked.

## Develop the plan

Applied instructions appear under **Planning prompts**, alongside the fields where you write the session. Blank fields remain unfinished. Prep checks use authored material, while a separate count shows how many template prompts still need development.

New clocks start at zero; new revelations and tasks start unchecked. Existing scenes, completed tasks, campaign pins, and other preparation retain their contents. The first live start copies authored material into the Live Session Desk; empty template entries stay in preparation. Applying a template while a desk exists preserves that desk's own progress and notes. See [SESSION_PREP.md](SESSION_PREP.md) for the prep-to-play workflow.

## Build your own library

Choose **New template** to write reusable instructions, or **Make an editable copy** of a starter. Saved custom templates support editing, duplication, deletion, optional entries, and row reordering. Their edits save automatically. Applied session copies retain their own contents when the library template changes or is deleted.

To reuse the arrangement of an existing plan, choose **Save this structure** in Session Prep or **Save this session’s structure** in the library. Capture retains the arrangement, scene types, suggested timing, and clock sizes, then supplies fresh generic planning prompts. Session-specific prose, references, original guidance, and play progress stay with the source preparation. Review or rewrite the captured instructions and choose **Save template** to add them to the global library.

## Save and recover

Use **Settings → Back up workspace** for a complete recovery copy, including the global custom library, pending application reviews, and applied prep. **Restore backup** replaces the workspace with the chosen backup, including its saved library. An older backup may predate your templates. A GM Markdown packet is a session reading copy; use the full workspace backup to restore the library.

Approved Archivist campaign refreshes preserve the global library and saved session preparation. Template editing pauses while a workspace replacement is in progress. If a library or template uses an unsupported newer format, its saved data is preserved and the template screen explains that it cannot be opened. Use a compatible app version to work with that data.

Templates and their reviews are GM material and stay outside Player preview and player search. They run locally in the desktop app, and in a browser once the application is cached for offline use. No AI connection is required to create, adapt, or apply them.
